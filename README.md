# Product Inventory

A PHP project scaffold for a product inventory application.

## Project Structure

```text
product-inventory/
├── index.php
├── login.php
├── logout.php
├── dashboard.php
├── add.php
├── list.php
├── view.php
├── edit.php
├── delete.php
├── upload.php
├── search.php
├── db.php
├── auth.php
├── categories.php
├── stock.php
├── low-stock.php
├── uploads/
└── css/
    └── style.css
```

The application uses PHP and MySQL to manage products, categories, and stock. The shared
stylesheet at `css/style.css` provides the dashboard and product-list layouts, as well as
consistent styling for category, stock, and product forms.
